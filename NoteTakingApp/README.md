# 📝 Note Taking App

A simple, clean and fast note-taking application built with **Node.js**, **Express.js** and **MongoDB**.

---
## ✨ Features

- Create, read, update and delete notes (CRUD)
- Simple and clean user interface
- MongoDB database storage
- Basic error handling

## 🛠️ Tech Stack

- **Backend**: Node.js + Express.js
- **Database**: MongoDB (with Mongoose)
- **Frontend**: EJS + plain CSS
- **Other**: dotenv, method-override

## 🚀 Quick Start (Local Development)

### 1. Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/) (v16 or newer recommended)
- [MongoDB](https://www.mongodb.com/try/download/community) (local or MongoDB Atlas cloud)

### 2. Installation

```bash
# 1. Clone the repository
git clone https://github.com/Nourhansherf/Learning-Backend-Journey.git

# 2. Go to project directory
cd NoteTakingApp

# 3. Install dependencies
npm install

# 4. To run the project : in your terminal
npm start

#5. Open your browser and go to:
→ http://localhost:3000

```
