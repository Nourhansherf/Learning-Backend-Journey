#TypeScript #javacript 

- TypeScript is same as JavaScript but allows you to detect error faster
---
#### To install TypeScript 
- First you have to use `Node.js` 
- Then install `tsc` using => `npm install -g typescript`
---
#### To transfer any file from typescript to JavaScript : 
```shell
tsc index.tsc
```
This will make you a `javascript` version of your typescript file.

- To make it dynamic so when you change your `tsc` file automatically changes the `js` file to 
	- `tsc -w index.tsc` => allow watch mode
