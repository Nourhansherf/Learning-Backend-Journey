#TypeScript #javacript 

- To make your basic typescript configuration => `tsc --init`
	- This will create you a `tsconfig.json` file which has all the typescript configuration you will need.
	- In this file you have to edit this configurations : ![[Pasted image 20260108133253.png]]
	- Add your `tsc` files in the `src` 
	- You don't have to add a `dist` folder by yourself
- After making your `tsc` files => `tsc -w` to sync all your `typescript` to be a `js` files.
	- Which is by default will create you the `dist` folder.
